# Gameplay screenshots

These images were captured from this project's native OpenGL renderer with the
supplied graphics profile and locally prepared optional art. The game rendered
a 2560×1600 world canvas; captures were resized to 1280×800 and metadata removed
for the README. The scene content was not generated or retouched.

| Image | View |
| --- | --- |
| [cockpit.png](cockpit.png) | Cockpit, cloud sky, static scenery and runway |
| [chase.png](chase.png) | External helicopter view |
| [terrain.png](terrain.png) | Terrain and extended visibility during a climb |

The PNG files are documentation images. The disc image, original files,
translated output, native executable, terrain grids, sky panoramas and model
packs used to produce them are excluded from the public source package.
